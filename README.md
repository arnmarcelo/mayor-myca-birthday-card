# 🎂 Mayor Myca Vergara — Interactive Birthday Card

A cozy, whimsical, mobile-first interactive birthday card created for **Mayor Myca Elizabeth R. Vergara** of Cabanatuan City, Nueva Ecija, sent with love and gratitude by her **CPDO (City Planning and Development Office) Family**.

Built with pure vanilla HTML5, CSS3, and modern JavaScript — zero heavy frameworks, instant tap feedback, and synthesized tactile Web Audio.

---

## ✨ Features & Walkthrough

1. **Slide 1 — Cozy Twilight Dark Room Opener:**
   - Starts in a dim twilight atmosphere with glowing fairy lights and an inviting glowing lantern.
   - Tapping *"Tap to Turn On the Lights"* illuminates the room with an authentic mechanical switch sound + warm chord shimmer.

2. **Slide 2 — Mayor Myca Greeting Card:**
   - Hand-framed portrait of Mayor Myca with a warm birthday dedication from Cabanatuan City, Nueva Ecija.
   - Optional Lo-Fi Rhodes birthday music toggle (`🎵 Music Off / On`) in the top-right header with zero initial bandwidth usage (`preload="none"`).

3. **Slide 3 — CPDO Family Message:**
   - Frosted warm-cream message card signed by the CPDO Family, expressing deep gratitude for Mayor Myca's inspiring leadership and visionary guidance for Cabanatuan City.

4. **Slide 4 — Hand-Painted Watercolor Cake Finale & Easter Eggs:**
   - Organic watercolor 2-tier birthday cake with ink outlines and 3 living, flickering candle flames.
   - Soft candlelight halo that breathes in real-time behind the cake.
   - Interactive tabletop Easter Eggs over the Cabanatuan Tricycle figurine, pastel gift box, and planning coffee mug.
   - Tapping the cake blows out the candles, produces airy whoosh + crystalline sparkle chime sounds, extinguishes the halo, releases celebration confetti, and reveals the birthday wish card.

## 🚀 Local Development

Simply open `index.html` in any modern web browser or serve locally with Python:

```bash
# Serve locally
python -m http.server 8088

# Open in browser:
# http://localhost:8088
```

---

## 🛠️ Tech Stack

- **HTML5:** Semantic, accessible markup with Open Graph & Twitter Cards for Viber, WhatsApp, and Messenger link previews.
- **CSS3:** Custom properties, CSS Grid/Flexbox, `@keyframes` flame flicker animations, responsive mobile-first sizing (`375px–430px`, `100dvh`).
- **JavaScript (ES6):** Vanilla DOM manipulation, touch-swipe detection, canvas confetti, and Web Audio API synthesis.
- **Zero Heavy Bundlers:** No build steps required. Instant deployment on Vercel, GitHub Pages, or Netlify.
